# Healthcare Website

A simple chatbot website where the user enters symptoms and the chatbot
suggests a disease name, health tips, and medicine name.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Type your symptoms in the chatbot.

## Disclaimer
This project is for learning purposes only. It is not a substitute
for professional medical advice.
